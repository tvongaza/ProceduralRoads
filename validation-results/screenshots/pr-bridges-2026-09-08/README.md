# Fords and bridges prototype PRs, in-game evidence (8 Sep 2026)

Two fixture worlds, three builds each (the #21 base, the fords branch, the
bridges branch on top of it), the network generated at load with
IslandRoadPercentage 100 and PathfindingMaxIterations 100000. metrics.csv:
label, roads, road length (m), route attempts that found no path,
pathfinding failures logged, generation seconds, crossing lines logged.
World A = the fixture used for the previous PRs; world B = the second
fixture. The jpgs are 1280 px previews of the captures.
